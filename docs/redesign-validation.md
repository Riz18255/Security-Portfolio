# Portfolio Testing & Design Notes

- Typography & styling: Space Grotesk for headings/body, JetBrains Mono for code and technical accents, dark lime/cyan/graphite palette.
- Case studies: Nine detailed case studies covering offensive security, detection engineering, and security systems. Coursework and practical lab cases (Forensics, Linux Vulnerability Assessment, Web Application Security) reflect actual academic coursework and hands-on exercises.
- Security Arsenal: 37 searchable tools, platforms, and languages. Descriptions clearly distinguish hands-on project implementations from lab and coursework practice.
- Visual assets: Official project marks and publisher logos sourced and attributed in `docs/asset-sources.json` and `docs/arsenal-asset-sources.json`.
- Responsive layouts: Verified across 320px, 390px, 768px, and 1280px widths, including 200% browser text zoom.
- Interactive features: Project area filter tabs, tool discipline filter, real-time search, tool detail dialog, global search palette (Ctrl+K), and audio toggle switch.
- 3D Sculpture: WebGL with Three.js, with a lightweight 2D canvas software fallback. Both respect OS reduced-motion preferences (`prefers-reduced-motion`) and pause when off-screen.
- CV: One-page PDF linked in the hero, header navigation, and contact section.
